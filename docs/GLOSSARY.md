# Glosarium

## Matematika

| Istilah | Arti |
|---|---|
| **Gradien (m)** | Ukuran kemiringan garis; perbandingan perubahan y terhadap perubahan x. Disebut juga *kemiringan*. |
| **Δy (delta y)** | Selisih nilai y dua titik: y₂ − y₁. Bagian "naik/turun". |
| **Δx (delta x)** | Selisih nilai x dua titik: x₂ − x₁. Bagian "jalan ke kanan". |
| **Rise over run** | Cara membaca gradien sebagai "naik ÷ jalan" (Δy/Δx). |
| **Bidang Kartesius** | Bidang dengan sumbu x (mendatar) dan sumbu y (tegak) yang berpotongan di titik asal (0, 0). |
| **Konstanta c** | Pada `y = mx + c`, nilai y saat x = 0 (titik potong sumbu y). |
| **Gradien tak terdefinisi** | Gradien garis tegak (Δx = 0) karena pembagian dengan nol. |
| **Garis sejajar** | Dua garis dengan gradien sama: m₁ = m₂. |
| **Garis tegak lurus** | Dua garis yang membentuk sudut siku-siku: m₁ × m₂ = −1. |

## Literasi dan Pemodelan

| Istilah | Arti |
|---|---|
| **Literasi matematika** | Kemampuan bernalar matematis serta merumuskan, menerapkan, dan menafsirkan matematika untuk memecahkan masalah dalam konteks nyata (PISA 2022). |
| **AKM Numerasi** | Asesmen Kompetensi Minimum bidang numerasi dalam Asesmen Nasional Indonesia. |
| **PISA** | *Programme for International Student Assessment* (OECD). |
| **Pemodelan matematika** | Proses mengubah situasi nyata menjadi model matematika, menyelesaikannya, lalu menafsirkan dan memeriksa hasilnya. |
| **Model linear** | Model berbentuk `y = mx + c`, dengan m = laju perubahan dan c = nilai awal. |
| **Laju perubahan** | Besarnya perubahan y untuk setiap 1 satuan x; makna kontekstual dari gradien. |
| **Nilai awal** | Nilai y ketika x = 0 (mis. biaya tetap, tabungan awal). |
| **Variabel bebas / terikat** | x (yang mempengaruhi) dan y (yang dipengaruhi). |
| **Invers (soal)** | Diketahui y, dicari x. |
| **Representasi ganda** | Satu situasi yang disajikan sebagai cerita, tabel, grafik, dan persamaan. |
| **Informasi pengecoh** | Data dalam soal yang tidak diperlukan untuk menjawab. |
| **Problem posing** | Kegiatan siswa membuat soal sendiri. |
| **Level konteks K-A s.d. K-D** | Tingkat kerumitan teks/stimulus soal cerita di GradieKAn. |
| **Jenis soal T1–T10** | Taksonomi soal cerita yang dapat dimodelkan aplikasi ([MATH_LITERACY §4](MATH_LITERACY.md)). |

## Teori Belajar

| Istilah | Arti |
|---|---|
| **Cognitive Load Theory (CLT)** | Teori bahwa memori kerja terbatas, sehingga pembelajaran perlu mengatur beban yang ditanggungnya. |
| **Intrinsic Load (IL)** | Beban dari kerumitan materi itu sendiri. |
| **Extraneous Load (EL)** | Beban dari cara penyajian yang tidak efektif; harus dikurangi. |
| **Germane Load (GL)** | Usaha mental yang membangun skema/pemahaman; perlu didorong. |
| **Skema** | Struktur pengetahuan di memori jangka panjang yang mengelompokkan banyak informasi menjadi satu kesatuan. |
| **Scaffolding** | Bantuan sementara yang memungkinkan siswa menyelesaikan tugas di atas kemampuan mandirinya. |
| **Fading** | Mengurangi bantuan secara bertahap agar siswa menjadi mandiri. |
| **Worked example** | Contoh soal yang diselesaikan lengkap langkah demi langkah. |
| **Completion problem** | Soal yang sebagian langkahnya sudah terisi; siswa melengkapi sisanya. |
| **Chunking / segmenting** | Memecah materi menjadi bagian kecil yang disajikan satu per satu. |
| **Signaling** | Memberi penanda (warna, sorotan, ikon) pada informasi penting. |
| **Split-attention effect** | Beban tambahan karena siswa harus menyatukan informasi yang terpisah (mis. rumus jauh dari gambar). |
| **Expertise reversal effect** | Bantuan yang berguna bagi pemula dapat menghambat siswa yang sudah mahir. |
| **Self-explanation** | Siswa menjelaskan langkah atau konsep dengan kata-katanya sendiri. |
| **Retrieval practice** | Mengingat kembali informasi untuk memperkuat ingatan (dasar Quick Recap). |

## Produk dan Teknis

| Istilah | Arti |
|---|---|
| **PRD** | *Product Requirements Document*: dokumen kebutuhan produk. |
| **MVP** | *Minimum Viable Product*: versi paling sederhana yang sudah bisa diuji. |
| **PWA** | *Progressive Web App*: situs web yang dapat dipasang dan berjalan *offline*. |
| **Capacitor** | Alat untuk membungkus aplikasi web menjadi aplikasi Android. |
| **IndexedDB** | Basis data bawaan peramban untuk menyimpan data di perangkat. |
| **Event log** | Catatan otomatis setiap interaksi penting siswa di aplikasi. |
| **MoSCoW** | Metode prioritas: Must, Should, Could, Won't. |
| **ADR** | *Architecture Decision Record*: catatan keputusan teknis beserta alasannya. |
| **E2E test** | Pengujian alur aplikasi dari ujung ke ujung seperti pengguna sungguhan. |
| **SUS** | *System Usability Scale*: kuesioner 10 butir untuk mengukur kegunaan. |
| **N-gain** | Ukuran peningkatan hasil belajar: (posttest − pretest)/(skor maks − pretest). |
| **JavaScript** | Bahasa pemrograman untuk aplikasi web/Android GradieKAn. |
| **JSDoc** | Komentar khusus di JavaScript untuk mendeskripsikan tipe data. |
| **Python** | Bahasa pemrograman untuk mesin matematika dan pemodelan GradieKAn. |
| **SymPy** | Pustaka Python untuk matematika simbolik (aljabar eksak). |
| **FastAPI** | Kerangka kerja Python untuk membuat API web. |
| **Pydantic** | Pustaka Python untuk mendefinisikan dan memvalidasi struktur data. |
| **API** | Antarmuka yang memungkinkan aplikasi meminta layanan dari server (mis. memodelkan soal). |
| **JSON Schema / Ajv** | Format untuk mendeskripsikan struktur JSON / pustaka JS untuk memvalidasinya. |
| **Parser** | Program yang membaca teks soal dan mengenali angka serta perannya. |
| **Vektor uji bersama** | Kumpulan kasus uji yang dijalankan di JavaScript dan Python untuk memastikan hasil keduanya sama. |
| **YAML** | Format teks sederhana untuk menulis data (dipakai untuk menulis soal cerita). |
